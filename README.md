# OOP — каталог товаров

Учебный проект на Python, демонстрирующий основные возможности
объектно-ориентированного программирования на примере товаров и категорий
интернет-магазина.

## Возможности

- создание товаров и категорий;
- использование абстрактного базового класса для общего интерфейса товаров;
- автоматический вывод информации о созданном объекте с помощью миксина;
- создание товара из словаря через классовый метод;
- получение и изменение цены через `property`;
- проверка новой цены на положительное значение;
- запрет создания товара с нулевым или отрицательным остатком;
- наследование специализированных товаров от класса `Product`;
- работа со смартфонами (`Smartphone`) и газонной травой (`LawnGrass`);
- добавление в категорию только объектов `Product` и его наследников;
- подсчёт созданных категорий и добавленных товаров;
- расчёт средней цены товаров в категории;
- вывод товара и категории в удобном строковом формате;
- сложение товаров одного типа с расчётом общей стоимости их остатков.

## Основные классы

### `BaseProduct`

Абстрактный базовый класс для товаров. Определяет обязательный интерфейс
инициализации и не предназначен для непосредственного создания объектов.

### `MixinInit`

Миксин, который при создании товара выводит в консоль имя его класса и основные
параметры. Формат диагностического сообщения задаётся методом `__repr__`:

```text
Product(Смартфон, Смартфон с OLED-дисплеем, 79990.0, 5)
```

### `Product`

Класс товара, наследующий `BaseProduct` и `MixinInit`. Хранит название,
описание, цену и количество на складе.
Цена находится в приватном атрибуте `__price` и доступна через свойство
`price`. Нулевое или отрицательное значение цены не устанавливается. При
попытке создать товар с нулевым или отрицательным количеством вызывается
`ValueError`.

Метод `new_product` создаёт товар из словаря. Оператор `+` вычисляет суммарную
стоимость остатков двух товаров одного класса.

### `Smartphone`

Наследник `Product`, описывающий смартфон. Дополнительно хранит:

- производительность (`efficiency`);
- модель (`model`);
- объём памяти (`memory`);
- цвет (`color`).

### `LawnGrass`

Наследник `Product`, описывающий газонную траву. Дополнительно хранит:

- страну-производителя (`country`);
- срок прорастания (`germination_period`);
- цвет (`color`).

### `Category`

Описывает категорию товаров и хранит название, описание и приватный список
товаров.

Классовые атрибуты:

- `Category.category_count` — количество созданных категорий;
- `Category.product_count` — количество товаров, добавленных в категории.

Метод `add_product` принимает только экземпляры `Product` и его наследников.
При передаче объекта другого типа вызывается `TypeError`.

Метод `middle_price` возвращает среднюю цену товаров категории. Для пустой
категории он возвращает `0`.

## Использование

### Создание товара

```python
from src.classes import Product

phone = Product(
    name="Смартфон",
    description="Смартфон с OLED-дисплеем",
    price=79990.0,
    quantity=5,
)

print(phone)
```

При создании объекта миксин сначала выводит диагностическую строку, а вызов
`print(phone)` — пользовательское представление товара:

```text
Product(Смартфон, Смартфон с OLED-дисплеем, 79990.0, 5)
Смартфон, 79990.0 руб. Остаток: 5 шт.
```

### Создание товара из словаря

```python
product_data = {
    "name": "Ноутбук",
    "description": "Ноутбук для работы и учёбы",
    "price": 99990,
    "quantity": 3,
}

laptop = Product.new_product(product_data)
```

Если нужного ключа нет, метод использует значение по умолчанию.

### Изменение цены

```python
laptop.price = 105000  # цена изменится
laptop.price = 0       # цена не изменится
```

При установке нулевой или отрицательной цены программа выводит:

```text
Цена не должна быть нулевая или отрицательная
```

### Сложение товаров

Оператор `+` возвращает суммарную стоимость всех единиц двух товаров:

```python
phone = Product("Смартфон", "OLED-дисплей", 79990.0, 2)
case = Product("Чехол", "Силиконовый чехол", 1990.0, 3)

total = phone + case
```

Расчёт выполняется по формуле:

```text
цена первого × количество первого + цена второго × количество второго
```

Складывать можно только объекты одного класса. При попытке сложить товары
разных классов вызывается `TypeError`.

### Специализированные товары

```python
from src.classes import LawnGrass, Smartphone

smartphone = Smartphone(
    "Samsung Galaxy S23 Ultra",
    "256GB, серый цвет, камера 200MP",
    180000.0,
    5,
    95.5,
    "S23 Ultra",
    256,
    "Серый",
)

grass = LawnGrass(
    "Газонная трава",
    "Элитная трава для газона",
    500.0,
    20,
    "Россия",
    "7 дней",
    "Зелёный",
)
```

Оба класса наследуют поля и поведение `Product`.

### Работа с категорией

```python
from src.classes import Category, Product

phone = Product("Смартфон", "OLED-дисплей", 79990.0, 5)
category = Category(
    name="Электроника",
    description="Смартфоны, ноутбуки и другая техника",
    products=[phone],
)

headphones = Product(
    "Наушники",
    "Беспроводные наушники",
    12990.0,
    10,
)
category.add_product(headphones)

print(category.products)
print(category)
print(category.middle_price())
```

Свойство `products` возвращает строку со всеми товарами категории. Строковое
представление категории показывает общее количество единиц товаров, а метод
`middle_price()` вычисляет среднюю цену по товарным позициям без учёта их
количества на складе.

### Обработка некорректного количества

Товар можно создать только с положительным количеством:

```python
Product("Смартфон", "OLED-дисплей", 79990.0, 0)
```

В этом случае будет вызвано исключение:

```text
ValueError: Товар с нулевым количеством не может быть добавлен
```
